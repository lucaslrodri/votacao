PARA O CORELDRAW · CDR

Arquivos para o formato do Corel

O CDR é o formato do CorelDRAW. Para ter o arquivo .cdr, envie estes SVG a um conversor online de SVG para CDR. São SVG simples, só com curvas (sem imagens embutidas e sem textos), que também abrem direto no CorelDRAW (Arquivo › Importar).
